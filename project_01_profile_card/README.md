# Profile Card

A simple Flutter profile card project built for practicing basic Flutter widgets and layout.

## Concepts Practiced

- `StatelessWidget`
- `MaterialApp`
- `Scaffold`
- `AppBar`
- `Column`
- `Row`
- `Container`
- `Padding`
- `Text`
- `Icon`
- `ElevatedButton`

## Goal

Practice building a simple UI by combining Flutter widgets into a widget tree.
