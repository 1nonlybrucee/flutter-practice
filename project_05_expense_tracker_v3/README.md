# Expense Tracker

A simple expense tracker app built with Flutter and Riverpod.

## Features

- Add, edit, and delete expenses
- Categorize expenses
- Filter by category
- Filter by period:
  - Today
  - This Week
  - This Month
  - This Year
  - All Time

- View total expenses
- View top categories
- Save expenses locally with SharedPreferences

## Technologies

- Flutter
- Dart
